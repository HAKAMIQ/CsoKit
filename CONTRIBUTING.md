# Contributing

CsoKit is a Windows x64 tool built with C# and .NET 10, with a native C++ compression backend (`native/`).

CsoKit is proprietary software (see `LICENSE.txt`). Contributions are accepted only by prior agreement with the maintainer.

Keep changes focused and small. Changes to container reading, compression, decompression, or output handling can affect every command.

## Requirements

- Windows x64
- PowerShell 7
- .NET 10 SDK
- CMake and Visual Studio C++ build tools, for the native backend
- Git
- GitHub CLI when working with CI or release workflows

## Build and test

```powershell
dotnet build CsoKit.slnx -c Debug
dotnet test CsoKit.slnx -c Release
```

Native integration tests need `CsoKit.Native.dll`; the release gate below builds and stages it.

## Release gate

Changes that affect packaging, the native backend, or release output must pass the consolidated gate:

```powershell
.\scripts\Run-ReleaseGate.ps1 -SkipRealIsoGates
```

Before a release, run the final gate on a clean working tree, with a real ISO when one is available:

```powershell
.\scripts\Run-FinalReleaseGate.ps1 -InputIso "C:\path\to\game.iso"
```

Do not assemble public releases by hand from `bin`, `obj`, or `artifacts`. Releases are published only by `.github/workflows/release.yml` from a signed `v*` tag.

## Releasing

1. Update `VERSION`.
2. Add a short `# CsoKit X.Y.Z` section to `RELEASE_NOTES.md`: what changed for users, and how to update. This section becomes the GitHub release page.
3. Run the final release gate and record its results in `docs/verification/X.Y.Z.md`. The release workflow refuses to publish without this file.
4. Merge through a pull request, then push a signed tag: `git tag -s vX.Y.Z -m "CsoKit vX.Y.Z"`.

## Manual tools

These scripts are not part of CI; run them when relevant:

| Script | Purpose |
| --- | --- |
| `scripts/Run-RealLocalCorpusGate.ps1 -Root <folder>` | Detect, verify, repair, and round-trip every ISO/CSO/ZSO/DAX file in a local folder. |
| `scripts/Test-CsoRoundtrip.ps1 -Exe <csokit.exe>` | Synthetic ISO→CSO→ISO audit, with an optional maxcso cross-check. |
| `scripts/Run-BenchmarkTruthLayer.ps1 -Root <folder>` | Measure compression results and timings into JSON and Markdown reports. |
| `scripts/Remove-Utf8Bom.ps1 [-Apply]` | Find (or remove) UTF-8 BOMs in source text files. |

## Test fixtures

Do not commit games, BIOS files, or real disc images. Small synthetic fixtures are allowed when they are generated by a committed script, such as `tests/CsoKit.Tests/Fixtures/Zso/make_zso_fixtures.py`.

## Before commit

```powershell
git status --short
git diff --check
.\scripts\Test-RepoTextEncoding.ps1
```

Commits to `main` are signed and go through a pull request.
